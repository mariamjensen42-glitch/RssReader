## 修复启动白屏闪烁

**问题**: 启动时先白屏→透明→再出现UI，体验差。

**根因**: Tauri v2 WebView2 在 Windows 上默认白色背景；body CSS `background-color: transparent` 让白色穿透；React/主题变量加载有时间差。

**最终方案**: 
1. `tauri.conf.json` → 窗口 `"visible": false` + `"backgroundColor": "#181818"`
2. `index.html` → 内联 `<style>` 用 `@media (prefers-color-scheme)` 立即设深色背景
3. `lib.rs` → `setup` 中 `std::thread::spawn` 延迟 300ms 后 `show()` 主窗口
4. 废弃 splashscreen 方案（setup 快，splashscreen 无意义）

**踩坑**: 尝试了 `getCurrentWebviewWindow()` polling（metadata 未就绪）、splashscreen（仍有原生闪）、`on_navigation`（API 不存在）。

## 实现 DeepSeek AI 文章处理

**模块架构**:
- `src-tauri/src/ai.rs` — DeepSeek API 客户端：`chat_completion()` + 4 个 prompt builder
- `lib.rs` — 4 个 Tauri 命令：`summarize_article`, `tag_article`, `translate_article`, `extract_viewpoints`
- Razor 板桥 `src/bridges/ai.ts` — 前端调用封装
- UI `src/components/ArticleAI.tsx` — 文章详情页底部 4 个按钮 + 结果面板
- 集成在 `ArticleDetail.tsx` 文章内容下方

**4 个功能**:
1. **Summary** — 3-5句文章摘要，temperature 0.3
2. **Auto Tags** — JSON数组返回标签，自动存数据库，同步到列表视图
3. **Translate** — 下拉选目标语言（中/英/日/韩/法/德），temperature 0.2
4. **Viewpoints** — JSON 输出观点数组 + 立场描述

**API Key 配置**:
- Settings 新增 `deepseek_api_key` + `deepseek_model` 字段
- 支持 env var `DEEPSEEK_API_KEY` 兜底
- 默认模型 `deepseek-chat`
