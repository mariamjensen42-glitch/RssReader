## RSSHub 路由浏览器集成

**用户需求**：把 RSSHub（3000+ 订阅源）引入项目，方便批量订阅。

**设计**：RSSHub 本质是 HTTP 服务，订阅 URL = 实例地址 + 路由路径，现有 addFeed 直接可用；价值在于把路由目录搬进应用。

- 后端 `fetch_rsshub_routes(instance)`：reqwest 走代理拉 `{base}/routes`（404 时 fallback `/api/routes`），**5 分钟内存缓存**（AppState 加 `rsshub_cache: Mutex<Option<(Instant, String)>>`），返回原始 JSON 字符串
- 前端新建 `src/bridges/rsshub.ts` + global.d.ts 注册 `window.rsshub`
- settings.tsx 新增 RssHubTab（挂在 General 与 About 之间）：
  - 实例地址输入（默认 https://rsshub.app，支持自建实例）+ Load Routes
  - 搜索框按站点名/路由路径/名称过滤（`siteEntries` useMemo）
  - 站点折叠列表（FolderRegular 图标 + 路由数），展开显示路由
  - 路由展开：正则 `/ :([a-zA-Z0-9_]+)\??/g` 扫描 `:param` 生成参数 Input（有 `parameters` 文档则显示描述，未填必选参数时 URL 含 `:` 禁用添加），URL 实时预览 → 一键 addFeed(url, "RSSHub")
  - routes 项兼容 string 与 object 两种格式（新老版本 RSSHub 返回不同）
- 踩坑：FluentUI v9 Input 无 `icon` prop，用 `contentBefore`
- 验证全过：tsc → cargo check → pnpm build（607KB，警告非错误）
